# Security and Privacy Baseline

- Minimize collection of personal data.
- Treat reflection text and assessment responses as private participant records.
- Do not collect psychotherapy, diagnosis, treatment, medical, legal, or financial-advice data through LISTEN learning forms.
- Use Supabase Auth + RLS for participant records.
- Keep server secrets out of client code and Git.
- Record consent purpose and version for program participation and optional feedback/testimonials.
- Separate operational evidence of training from public testimonials; publication requires appropriate consent.
- Establish retention/deletion rules before collecting substantive participant reflections in production.
