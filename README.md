# THE LISTEN MODEL™ Website — v0.4

v0.4 corrects the site to the owner-confirmed L.I.S.T.E.N. framework and establishes the backend/documentation baseline.

## Canonical public framework
L — Listen  
I — Interpret the Language  
S — Specify the Goal  
T — Tailor to the Style  
E — Evaluate the Confidence, Commitment, and Show Compassion  
N — Navigate the Support Strategy

Presence, Interpretation, Clarification, Reflection, and Response remain supporting foundational practices; they are not the acronym. Advanced LMBOK lenses and protected practitioner mechanics are intentionally not published on public pages.

## Run locally
```powershell
npm install
npm audit
npm run build
npm run dev
```
Then open `http://localhost:3000`.

## Environment
Existing Resend form variables remain supported in `.env.local`:
`RESEND_API_KEY`, `TRAINING_REQUEST_TO`, `TRAINING_REQUEST_FROM`.

A live Supabase project is not required for v0.4. Future variables are documented in `docs/SUPABASE_SETUP.md`.

## Important docs
Start with `docs/MASTER_FRAMEWORK.md`, `docs/PUBLIC_CONTENT_RULES.md`, and `docs/PROTECTED_CORE.md` before changing framework language.
